# EPAM IT Marathon 2026. Manual QA #7

Основний результат — **EPAM_HW7_Manual_QA_US11.xlsx**. Починайте з аркуша «Підсумок».

Для здачі підготовлено [готовий XLSX у GitHub](EPAM_HW7_Manual_QA_US11.xlsx) та [єдиний перелік посилань](../../HOMEWORK_SUBMISSION.md). Google Sheets import/publication не виконувалися; нижче збережено фактичні результати та обмеження перевірки.

Книга містить 49 тест-кейсів, 21 питання до вимог, трасування AC1–AC5, реєстр фактичного виконання, один підтверджений дефект і вбудовані зображення. Вкладки Test cases та Defect reports зберігають структуру оригінального шаблону; їхній вміст українською.

Підсумки: Passed 13; Failed 3; Blocked 24; Not Run 9; Not Applicable 0. Перевірки гостьової функції, статичного скриншота, публічного EPAM-меню та Figma розділені. Два failed-тести реалізації стосуються одного дефекту фото. Окремий Failed у Figma — суперечності цін/суми макета.

EPAM-стенд доступний, але надане гостьове запрошення не завантажується. Тому особистий subcart, фактична заборона On Stop та актуалізація після контрольованої зміни серверних даних не підтверджені. Працездатні prototype connections не підтверджені; Present відкрито лише як перегляд кадру.

Докази вбудовано у книгу та додатково збережено в evidence/. Оригінальний скриншот із повною адресою запрошення виключено. Файл US11_source.pdf — наданий вихідний документ. E25/E26 підтверджують відкриття зведення й зображень у Microsoft Excel; вони не є тестами EPAM-продукту.

Публічне посилання не створено. Після погодження власником та незалежної перевірки книгу можна імпортувати в Google Sheets. Після імпорту перевірте формули, об’єднання клітинок, зображення та внутрішні посилання, а тоді надайте посилання для перегляду без авторизації. Цей крок ще не виконано.
